# Starter plugin selection

Checked 2026-09-27 against the [official directory](https://github.com/obsidianmd/obsidian-releases/blob/master/community-plugins.json) and [official download statistics](https://github.com/obsidianmd/obsidian-releases/blob/master/community-plugin-stats.json). This is an editorial selection by workflow, not a ranking or a claim that every beginner needs all twenty. Download counts include updates. Home only links to official plugin details; it never installs automatically.

The implementation is original and copies no third-party source code. Descriptions are short independent summaries of the capabilities in the official registry. Advanced/setup-dependent tools are labeled. No runtime network request is needed to load the list.
