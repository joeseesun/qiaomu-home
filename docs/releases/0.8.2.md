# 0.8.2

Pane dividers now follow the visible reading/chat palette, including mixed light and dark workspaces. Hover and drag feedback stays neutral, while native hit areas remain unchanged. Hidden tabs and unrelated note panes retain the host appearance. Each family plugin works independently and cleans up its divider styles on unload.

The divider segment beside native tabs retains the Obsidian theme; only the content segment adopts the panel palette. Both light and dark host themes are supported.
